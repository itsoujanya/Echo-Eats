Echo-Eats 

Echo-Eats is an AI-powered voice-enabled food ordering platform developed using React.js, Django, Python, NLP, and MySQL. The application allows users to browse menus, interact through voice commands, and place food orders seamlessly using speech recognition technology.

Features
- Voice-based food ordering
- AI-powered interaction using NLP
- User authentication and secure login
- Restaurant and menu browsing
- Real-time order management
- Responsive modern UI

Tech Stack
- Frontend: React.js
- Backend: Django
- Database: MySQL
- AI/NLP: Python, Speech Recognition

Goal
To simplify and modernize the food ordering experience through intelligent voice interaction.
